# 🖼️ Image Renamer v15

이미지 파일의 이름을 일괄 변경하고, 원하는 순서대로 정리하며, 메타데이터를 제거할 수 있는 Windows용 이미지 관리 도구입니다.

이미지를 하나씩 수정할 필요 없이 여러 파일을 한 번에 관리할 수 있습니다.

---

## ✨ 주요 기능

### 1. 일괄 이름 변경
- 여러 이미지 파일을 한 번에 불러오기
- 기본 이름과 시작 번호 지정
- 이미지 순서 조정
- 지정한 규칙에 따라 파일 이름 변경

### 2. 엑셀식 이름 지정
- 이미지별로 원하는 이름 배정
- 행과 열을 이용한 이미지 정리
- 행 및 열 이름 사용자 지정
- 표의 각 칸에 이미지를 직접 배치

### 3. 저장 및 메타데이터 관리
- 원본 파일 이름 변경 또는 별도 폴더에 복사하여 저장
- 일반 폴더 또는 ZIP 압축파일로 저장
- JPG, PNG, WebP 형식으로 변환
- 이미지 메타데이터 제거 옵션 제공
- 저장 후 메타데이터 검사

### 4. 지원 이미지 형식
- JPG / JPEG
- PNG
- WebP
- BMP
- TIFF / TIF

## 💻 실행 방법

### 방법 1. Windows 실행 파일 만들기

1. 위의 ZIP 파일을 다운로드합니다.
2. 원하는 폴더에 압축을 해제합니다.
3. Python이 설치되어 있는지 확인합니다.
4. `Build_EXE.bat` 파일을 실행합니다.
5. 필요한 패키지가 설치되고 빌드가 완료될 때까지 기다립니다.
6. 생성된 `dist` 폴더 안의 `ImageRenamer.exe`를 실행합니다.

빌드 과정에서 인터넷 연결이 필요할 수 있습니다.

### 방법 2. Python으로 실행하기

Python이 설치되어 있다면 압축을 해제한 폴더에서 명령 프롬프트를 열고 다음 명령어를 실행합니다.

```bash
py -m pip install pillow
py ImageRenamer.py
